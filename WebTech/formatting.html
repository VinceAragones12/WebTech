Activity

HTML stands for HyperText Markup Language.

HTML provides different tags that can be used to format, emphasize, underline, and highlight text.

Explanation of Each Tag

  • <b> — Makes text bold.
  • <strong> — Indicates text with strong importance.
  • <i> — Displays text in italic style.
  • <em> — Emphasizes text.
  • <u> — Underlines text.
  • <mark> — Highlights text.
  • <small> — Displays smaller text.
  • <del> — Shows deleted or removed text.
  • <ins> — Shows inserted text.
  • H2O — <sub> creates subscript text.
  • E = mc2 — <sup> creates superscript text.
